Introduction to Bootstrap

Bootstrap is a free and open-source front-end framework that helps developers design and build responsive, mobile-first websites quickly and efficiently. It provides pre-styled components, a responsive grid system, and utility classes, reducing the time and effort needed for web development.

Important Features

  • A flexible grid system allows you to create layouts that adjust to different screen sizes
  • Based on a 12-column layout. Predefined classes for creating layouts (e.g., .col-md-6 for half-width on medium devices). Supports flexible and nested grids.

  • Ready to use UI components save time and effort

  • Easily customize style and themes using Sass ariables.
  • change color, fonts, spacing and more.build unique themes using theming system.

  • Ensure consistent performance across all major browser.

  • Predefined classes to add styling without writing custom CSS.

  • Interactive components powered by javascript.

  • Support icon libraries like Bootstrap icons, font awesome, or custom SVG icons.

Bootstrap Grid System

The Bootstrap grid system is a flexible and responsive layout system that divides a page into a 12-column grid. It allows you to create responsive designs by defining how content should be displayed across different screen sizes. Here's an overview of how it works

Key Concepts of the Bootstrap Grid System

Container:
The grid system is wrapped inside a .container or .container-fluid element.
.container: Provides a fixed-width container that adjusts based on the screen size.
.container-fluid: Provides a full-width container that spans the entire width of the viewport.
Rows:
Rows (.row) are used to create horizontal groups of columns.
Each .row ensures proper alignment and spacing between columns.
Columns:
The grid system divides each row into 12 columns.
Use classes like .col, .col--, where: specifies the screen size (sm, md, lg, xl, xxl). specifies the number of columns (1 to 12).

How It Works

  • Grid System Classes: Classes like .col-md-6 apply specific widths (50% in this case) at a defined breakpoint (≥768px).
  • Percentage-based Columns: Columns are based on percentages, ensuring they adjust fluidly across screen sizes.
  • Flexbox: Bootstrap's grid system is powered by Flexbox, which provides modern alignment and distribution capabilities.
